Execution tasks are records in the `cps_task` table that Travel Agent Operations uses to track background work. Each task has a type and may be linked to a parent task. Some task types are automated or intended for internal use, so check with your administrator before creating or changing a task.

## Task fields

| Field | Description |
| --- | --- |
| Task record ID (`cps_taskid`) | Unique identifier for the task record. |
| Task ID (`cps_id`) | Text identifier associated with the task. |
| Parameters (`cps_parameters`) | Task-specific parameter data. The schema reference does not define its format or required values. |
| Task results (`cps_taskresults`) | Results associated with the task. |
| Task type (`cps_executiontasktype`) | Identifies the kind of task. The task type name is stored in `cps_executiontasktypename`. |
| Priority (`cps_priority`) | Priority value assigned to the task. |
| Parent task (`cps_task_parent`) | Links the task to a parent task, when applicable. The parent task name is stored in `cps_task_parentname`. |

The application may also display task status and stage. The database reference does not specify their available labels, so confirm those values in your environment.
